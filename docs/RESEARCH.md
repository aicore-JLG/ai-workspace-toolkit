# Research that leads to a decision

1. Define the decision, question, freshness and constraints.
2. Search the selected project and permitted Knowledge entries first.
3. Use Agent Search for public tools, or your optional Agent Reach installation for supported public platforms.
4. Open original sources. Record publisher, date, finding, uncertainty and reuse permission.
5. Separate observation from interpretation and preserve contradictions.
6. Return supported findings and the next decision. Store only permitted reusable material.

Use [research-to-decision](../workflows/research-to-decision.md), [knowledge retrieval](../workflows/knowledge-retrieval.md) and [social outliers](../workflows/social-outlier-research.md).

No real profiles, accounts, search history or results are bundled. Research does not authorise private data collection, access circumvention or tool installation.
