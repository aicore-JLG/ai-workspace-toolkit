# Put your clean copy on GitHub

No repository or account is preconfigured.

1. Start from the untouched release in a new folder; review hidden files too.
2. Choose a repository name and visibility in your own account.
3. Initialise Git, stage only reviewed files and inspect the staged diff/file list.
4. Commit locally. Add your intended remote and push when you intend to publish.
5. Host the separate guide page by uploading its HTML, CSS, JavaScript and downloads together.

Ignore patterns do not remove tracked files or secure data. Never publish a populated personal workspace. Repository and page audiences depend on your chosen settings.
