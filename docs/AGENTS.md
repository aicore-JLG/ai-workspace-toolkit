# Your specialist directory

These are original AI role briefs, not running employees or account connections.

| Role | Job | Expected return |
|---|---|---|
| [Planner](../roles/planner.md) | Define a bounded plan | Acceptance checks, files, dependencies and risks |
| [Builder](../roles/builder.md) | Implement the agreed change | Working artifact, checks and limits |
| [Reviewer](../roles/reviewer.md) | Independently assess the artifact | Concrete defects against requirements |
| [Researcher](../roles/researcher.md) | Answer a decision question | Sources, findings and uncertainty |
| [Debugger](../roles/debugger.md) | Explain and repair failure | Reproduction, cause and regression check |
| [Web designer](../roles/web-designer.md) | Create a usable website | Structure, visual rules, responsive artifact and QA |
| [Funnel strategist](../roles/funnel-strategist.md) | Connect offer and fulfilment | Journey, promises and delivery requirements |
| [Copywriter](../roles/copywriter.md) | Write supported, purposeful copy | Copy, evidence gaps and voice decisions |
| [Email writer](../roles/email-writer.md) | Prepare fulfilment/follow-up emails | Subject, body and delivery checks; no sending |

Use [routing.json](../routing.json) with [launch packets](LAUNCHERS.md). Give the maker the project, outcome and selected sources. Give the reviewer original requirements, final artifact and check evidence, without a persuasive account of the maker's success.

If your AI supports independent subagents, use a separate context. Otherwise start a fresh conversation with the reviewer brief. Self-review is not independent review.
