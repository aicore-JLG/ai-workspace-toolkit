# Knowledge register

Keep reusable, permitted knowledge here. Project records and client information stay with their owning project.

| Source | What it helps with | Owner and permission | Last checked | Status |
|---|---|---|---|---|
| `source-template.md` | Format for recording one reusable source | Blank template supplied with this kit | Not populated | Template only |

Add only sources you have the right to use. Link to the original and record its date, uncertainty and usage limits. Do not copy a complete external library here just to make it searchable. A citation is not permission to redistribute.

For a task, select the smallest relevant source set. Read the current source before relying on a stored summary. Keep contradictory findings visible rather than silently merging them.
