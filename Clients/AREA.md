# Clients

Use a separate scope for each client. Start from `templates/project/` at the workspace root only when you are authorised to work on that client.

Do not put real client records in this distribution copy. In your own working copy, keep client instructions, state and materials inside the relevant client project. Never mix them into a shared template or another client's work.

Folders alone do not enforce isolation. Use separate workspaces and appropriate tool/account access controls when handling confidential work.
