# Research brief

Follow workflows/research-to-decision.md and roles/researcher.md from the known kit root. State the question and decision it supports before gathering material.

Use current primary sources when facts can change. Record URLs or permitted local references, dates, findings, contradictions and unanswered questions. Never treat snippets as full source inspection.

Keep private records within their owning project. Optional Agent Reach or search connectors need the user's own setup and access; a research request does not authorise installing them or importing cookies.

Return the supported answer, uncertainty and a concise recommendation when requested. Store only permitted reusable knowledge in the shared register.
