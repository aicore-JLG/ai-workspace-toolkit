# Retrieve the smallest useful source set

1. Name the task and owning project. Read its brief and state.
2. Select permitted relevant Knowledge entries, without traversing other projects.
3. Read each original source, date, permission and uncertainty.
4. Keep contradictions visible. A summary never overrides its source.
5. Give the AI a short source list explaining what each supports.
6. Cite important claims and keep derived notes with their owner.
7. Update the register only with authorised reusable material.

Use local map/context commands and scoped text search. This workflow installs no search index, embedding database or retrieval service.
